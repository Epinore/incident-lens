# Hand-labeling guide (for the teammate)

Open `gold_to_label.csv` in Excel or Google Sheets. For each row, read `text` and
type ONE of these codes in `my_label`. Aim for 50 rows in ~45 minutes. Don't overthink:
go with your first read, write doubts in `notes`.

| code | category | ask yourself | typical words |
|---|---|---|---|
| EQ  | Equipment failure | Did a *thing* break, wear out, leak, corrode or malfunction? | failed, corroded, sheared, leaked, worn, malfunction |
| HU  | Human performance error | Did a *person* do the wrong thing / skip a step / misjudge? | failed to, did not, improperly, inattention, misjudged |
| MS  | Management systems | Was a *procedure, policy, plan or JSA* missing or inadequate? | no procedure, inadequate JSA, policy, MOC, inspection program |
| SU  | Supervision | Did a *supervisor/lead* fail to oversee, enforce or plan the job? | supervisor, oversight, not enforced, person in charge |
| CO  | Communication | Was information *not passed on or misunderstood* between people? | radio, instructions, not communicated, misunderstood, handover |
| WE  | Work environment | Did *conditions* cause it: weather, layout, lighting, slippery deck, congestion? | weather, slippery, lighting, congested, sea state |
| ?   | Can't tell / empty text | Leave a note why | |

Rules
- Pick the ONE best fit, even if two seem to apply (note the 2nd in `notes`).
- Do NOT copy any person or company names into notes or slides.
- These are real injury reports. Stop anytime if it's upsetting.
- When done, save as CSV (keep the same filename) and tell Ethan how many rows you labeled.
